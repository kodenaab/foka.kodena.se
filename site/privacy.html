Appen arbetar lokalt

Foka tonar ned skärmen med ett transparent överlägg. Appen spelar inte in skärmen, hämtar inga presentationsbilder och skickar inte presentationsinnehåll till någon server. Inget användarkonto behövs. Foka har ingen egen telemetri, reklam eller analys av användarbeteende.

Lokal diagnostik

En diagnostiklogg sparas i Fokas mapp för lokala appdata. Den kan innehålla tidsstämplar, skärmegenskaper, tekniska fel och sökvägar som innehåller användarnamn. Den innehåller inga presentationsbilder och skickas inte automatiskt. Om du kopierar eller skickar diagnostik till support väljer du själv vilken information du delar. Granska texten först.

Webbplats och nedladdningar

Webbplatsen är förberedd för GitHub Pages. GitHub uppger att besökares IP-adresser loggas och lagras för säkerhetsändamål. Nedladdningsknapparna hämtar uppgifter om den senaste publika releasen via GitHubs API, och appfilerna hämtas från GitHub Releases. Besökarens webbläsare ansluter då till GitHub. Se GitHubs integritetspolicy. Webbplatsen använder inga egna analysverktyg eller spårningscookies.

Kontakt med support

Om du mejlar supporten delar du din e-postadress och uppgifterna i meddelandet med Kodena för att ditt ärende ska kunna besvaras. Skicka inte elevuppgifter eller annat känsligt innehåll. Kontakta foka@kodena.se om du vill fråga om hanteringen av ditt ärende eller begära radering av uppgifter du skickat.

Operativsystem och appbutiker

Operativsystemets diagnostik och distribution via en appbutik omfattas av respektive leverantörs villkor och integritetspolicy. Fokas egen funktion kräver inte skärminspelningsbehörighet.
